# NFLMeta API client

Official client library for the [NFLMeta API](https://nflmeta.org/api-docs).

TypeScript package: `@nflmeta/sdk`. Python package: `nflmeta`.

For authentication, examples and endpoint documentation, see the
[SDK guide](https://nflmeta.org/api-docs/sdk).

Client tests use mocked responses. This package is MIT licensed; see `LICENSE`.
